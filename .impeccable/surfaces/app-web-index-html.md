# Surface brief · MAX EDITOR app window (Tomas y referencias + Retocar)

Mode: Operate. Code-led (Operate surface). Audience: the creator making H3 music edits on their own PC; secondary: contest judges watching the demo video. Task: write shots, connect references, set duration, generate, retouch. Constraints: keep every function and the P10 layout (phase bar on top, compact toma panel, Principal | Secundarias shelf above the timeline, timeline, sound at the bottom; all on one 2548×1284 CSS screen without scroll). Old themes (azul, trama) were removed on 28 oct 2026; casete is the only theme. User feedback (27 oct 2026) on «Trama»: «solo blanco y negro… 0 distinción entre todo, no resaltaba lo importante, todo era igual de monótono y abrumador»; wants something «único y raro». Chosen in round r3: «Mixtape de casete» (the roll).

## Direction contract

THESIS: The edit is a mixtape: each shot is a numbered track on side A, each reference a round colour sticker stuck on the tracks it plays in; it refuses the grey dark-editor default and the monotone sheet the user rejected, by giving every level of importance its own colour weight.

OWN-WORLD: Ink ground #17121C; one action orange #FF7A1A as the J-card band (Generar, active phase, chosen shot, ACCIÓN field, active toggles) and nothing else; cobalt #2546D6 tints the reference shelf and the text track; pink #FF3E8A as a thin accent stripe; cream #F6EAD2 only on labels (project, poster captions, track labels), never as page ground. Reference colours are round stickers. Type: Big Shoulders Display for titles and Generar, Barlow Condensed for labels, Barlow for text, JetBrains Mono tabular for seconds, frames, seed and prompt. No neon glow; hard offset shadows only on Generar.

STORY: The creator reads the screen like a tape: which side they are on, which track is chosen, which stickers sit on which track, and the one orange Generar; nothing else competes.

FIRST VIEWPORT: Header with MAX EDITOR, project label, statuses, seed + otra semilla, orange Generar with pink offset shadow, Videos. Phase bar: «Cara A · 1 · Tomas y referencias» as the wide orange J-card band with mini status, «Cara B · 2 · Retocar» quiet. Toma panel with orange-edged ACCIÓN. Cobalt shelf «Principal | Secundarias» with cream-captioned posters and sticker stamps. Timeline: tracks «A1», «A2» sized to their duration with s and f, stickers on them, a newly connected sticker ringed «recién pegada»; waveform as brown tape; sound field last.

FORM: «Mixtape de casete» (J-card cassette sleeves and mixtape stickers), grounded candidate 5, assigned by the roll and chosen by the user in round r3. seed:0ca6570fb013ef4a

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
